# 锚库（你的道藏）

每个主题一个文件。格式：

```markdown
## 锚 N：<一句话可证伪命题>

- 证据等级：FACT 支持 / 部分支持 / 假设
- 检验履历：<每次触发器检验：日期 事件 → 通过/推翻>（连续通过 = 信念升档的依据）
- 路径阶段：萌芽 / 发酵 / 定价 / 兑现（定价阶段不锚）
- 锚定领先度：锚定时市场共识是 <X>（复盘时记录共识何时转向）
- 更新触发器：<哪个事件会改变这条锚>
- 关联：<未决问题编号或证据编号>
- 建立：YYYY-MM-DD（来源：哪次研究）

[失效] 的锚保留原文 + 推翻它的事实，不删除——教训是你的资产。
```

规则（见 SKILL.md「认知锚的持久化」）：
- 研究开始前先读相关主题的锚文件；
- 研究结束后更新/新增，每主题活跃锚 ≤5 条；
- 锚必须能被单一事实更新（可证伪），否则它只是笔记；
- **证否是刹车，信念是引擎**：只靠证否不会赢——锚的价值在检验履历的累积和领先度的记录。
- `index.md` 是总仪表盘，每次研究结束同步。
- 以 `_` 开头的文件是模板/示例（如 `_example.md`），不参与触发器体检。
- 日期优先写完整 `YYYY-MM-DD`。裸 `M/D` 按当前年解释；错过后持续标为 overdue，直到锚被更新。要约到下一年必须显式写下一年的年份。
