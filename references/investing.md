# 投资研究 profile

只在问题涉及证券、公司经济暴露、行业利润池、价格、估值或市场预期时加载本文件。继续以 `SKILL.md` 的原子主张卡为语义单位。

## 把主题还原为经济暴露

对主题、政策、技术或工程事件，逐段检查：

```text
需求或政策
→ 工程/产品可行性
→ 具名客户与合同
→ 交付
→ 验收、起租或计费
→ 收入
→ 毛利
→ 回款与自由现金
```

前一段成立不能自动证明后一段。技术相关、产业链归属、框架协议、规划产能、合同总额、设备到场和工程量，都不能直接替代可归属收入、利润或现金。

只有来源能把同一业务、产品、客户或订单批次按一致时间与口径跨段连接，才可写“订单→交付→收入→毛利→回款链条已闭合”。公司整体积压、收入、利润和经营现金流只能证明公司级汇总经营结果，不能拼接成某个订单批次或产品线的同一血缘链；无法归属时分段陈述，并把专项暴露保留为 `NOT_EVALUABLE`。这项禁令同样适用于“公司合并口径”：若积压/订单与期间收入、利润或现金没有同一批次血缘，只能写这些公司级观察同时存在，不得写链条闭合、订单转化或回款兑现已被证明。

交付前对标题、根结论和摘要做三项闸门：

1. 任一订单链环节未知或无法同血缘归属，就不得写“链条已闭合”；
2. 任务限定来源资格时，订单、交付、业绩归属、共识、价格与估值的每个承重输入都必须来自合格来源；二手站点只可定位，不得用“规范原始”等名称升级资格；
3. “收购补强全链能力”、“合作证明竞争力”等包含能力或因果解释的整句主张标为 `INFERENCE`，不标 `FACT`。

必须等本文件完整读取结果返回后，才可发出第一项外部研究调用；不得把 profile 读取与搜索并行。A 股研究的第一项外部调用固定为 Skill 安装根目录下的官方披露索引器：

```text
python3 <skill-root>/scripts/ashare_disclosures.py --ticker <六位代码> --as-of <YYYY-MM-DD>
```

索引覆盖最新完整定期报告以来与 120 天取长者，并分类检查可能改写结论的融资、限售、质押、担保、诉讼、回购、控制权和治理事项。返回 `UNAVAILABLE`、覆盖不完整或命令失败时，不自动改用同义搜索补洞；依赖该索引的现状与“未发现”维度一律为 `INSUFFICIENT`。网页搜索只定位候选，承重前必须打开并读取具名原始披露；搜索摘要、转载和产业链共现不能替代官方索引或原件。

## 可能性与市场层

需要比较路径时，至少保留基准、上行和下行解释，但不要为了格式虚构三种对称答案。每条路径只列 2–4 条真正承重的主张卡，并标出最早可验证信号。

把以下四层分开：

1. 工程或产品事实；
2. 公司可归属的经济暴露；
3. 市场已经定价的预期；
4. 对投资决策的条件影响。

价格和估值必须有 as-of、来源、单位与可比口径。若决定利润池、订单/毛利或价格/估值的根输入仍为 `SINGLE_SOURCE` 或 `INSUFFICIENT`，不要写“唯一候选”“最可能”“未充分定价”，也不要用任意阈值制造 setup；降为 `WATCH_ONLY` 或 `NOT_EVALUABLE`，并指出哪条一手事实可以升级。

把“没有被材料证明”与“现实中没有形成”分开。若证据包只是没有提供客户通知、订单、收入或回款，只能写“未被证据闭合”“包内未观察到”或 `NOT_EVALUABLE`，不得写“未收到”“未形成”“不存在”或含义相同的“无可归属暴露”。“后续以正式通知为准”也不证明通知尚未收到；只有具名一手事实明确否认、终止或确认未发生，才可形成对应的否定主张。

这条约束同时适用于标题、根结论、摘要、表格和主张卡，不能在后文纠正而让承重结论保留越界表述。任一承重缺口为 `INSUFFICIENT` 时，根结论固定写成：`截至 {as_of}，公开证据支持 {facts}；尚未闭合 {gaps}。现实中是否已经形成 {target} 未知，因此当前为 NOT_EVALUABLE。` 花括号必须替换为本题对象；不得用“不成立、未形成、不存在、没有项目、闭环未闭、为空、尚无收入”等现实否定同义改写，除非具名一手事实明确否认。

时态逐卡低自由度执行：没有额外证成时默认 `EVENT_BY_DATE`；`STATE_AT_AS_OF` 必须在观察栏写明具名来源覆盖至哪个 as-of；`ABSENCE_BY_AS_OF` 必须写明枚举的官方索引或封闭语料及起止日期。历史事件、当前状态和范围内未发现是三条不同主张，不得塞进一张卡后只给一个时态。

## 非对称审计

按问题选用以下模块：

- 主题层：瓶颈排序、利润池位置、替代技术和迁移条件；
- 公司层：业务口径、客户、合同、收入、毛利、现金与融资约束；
- 市场层：共识、价格/估值、拥挤代理、尚未定价的分叉；
- 时间层：事件日、战术周、业绩季度、结构年份分别判断；
- 行动层：触发器、失效条件和唯一最低成本下一验证。

常见错误：需求增长不等于便宜；政策目标不等于公司受益；预案不等于生效规则；签约产能不等于交付；单一机构事件不等于行业结论；热门名单不等于价值捕获；供需同时变化时不能压成一条因果。

## 完整报告格式

只有用户要求完整投资报告时，按需组合：

1. 根结论、适用时间和唯一下一步；
2. 可能性地图；
3. 承重主张卡与最弱环节；
4. 主题利润链和公司经济暴露；
5. 已定价 / 未定价对照；
6. 不超过 3 个具名载体或明确说明没有可用载体；
7. 反例、证伪条件和未决问题；
8. 决定性主张 `[C#]` × 来源 `[E#]` × URL × 发布日期。

长度服从信息量。投资语义只属于本 profile，不得成为非投资任务的默认输出合同。

## 可选市场数据脚本

需要 A 股官方披露索引时先运行 `scripts/ashare_disclosures.py`；需要价格硬锚时可运行 `scripts/free_market_observations.py`。输入、输出与凭据边界以脚本帮助为准；输出只提供观察，不自动形成推荐。Tushare token 不进入提示、报告、锚或仓库。通用原始数据可按需使用 `scripts/tier1_providers.py`。
