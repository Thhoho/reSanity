# 投资研究 profile

只在问题涉及证券、公司经济暴露、行业利润池、价格、估值或市场预期时加载本文件。继续以 `SKILL.md` 的原子主张卡为语义单位。

## 把主题还原为经济暴露

对主题、政策、技术或工程事件，逐段检查：

```text
需求或政策
→ 工程/产品可行性
→ 具名客户与合同
→ 交付
→ 验收、起租或计费
→ 收入
→ 毛利
→ 回款与自由现金
```

前一段成立不能自动证明后一段。技术相关、产业链归属、框架协议、规划产能、合同总额、设备到场和工程量，都不能直接替代可归属收入、利润或现金。

只有来源能把同一业务、产品、客户或订单批次按一致时间与口径跨段连接，才可写“订单→交付→收入→毛利→回款链条已闭合”。公司整体积压、收入、利润和经营现金流只能证明公司级汇总经营结果，不能拼接成某个订单批次或产品线的同一血缘链；无法归属时分段陈述，并把专项暴露保留为 `NOT_EVALUABLE`。

交付前对标题、根结论和摘要做三项闸门：

1. 任一订单链环节未知或无法同血缘归属，就不得写“链条已闭合”；
2. 任务限定来源资格时，订单、交付、业绩归属、共识、价格与估值的每个承重输入都必须来自合格来源；二手站点只可定位，不得用“规范原始”等名称升级资格；
3. “收购补强全链能力”、“合作证明竞争力”等包含能力或因果解释的整句主张标为 `INFERENCE`，不标 `FACT`。

上市公司研究先枚举截至 as-of 可见的官方披露索引。覆盖最新定期报告以来与 120 天取长者，并检查可能改写结论的融资、限售、质押、担保、诉讼、回购、控制权和治理事项。关键词搜索不能替代索引枚举。

## 可能性与市场层

需要比较路径时，至少保留基准、上行和下行解释，但不要为了格式虚构三种对称答案。每条路径只列 2–4 条真正承重的主张卡，并标出最早可验证信号。

把以下四层分开：

1. 工程或产品事实；
2. 公司可归属的经济暴露；
3. 市场已经定价的预期；
4. 对投资决策的条件影响。

价格和估值必须有 as-of、来源、单位与可比口径。若决定利润池、订单/毛利或价格/估值的根输入仍为 `SINGLE_SOURCE` 或 `INSUFFICIENT`，不要写“唯一候选”“最可能”“未充分定价”，也不要用任意阈值制造 setup；降为 `WATCH_ONLY` 或 `NOT_EVALUABLE`，并指出哪条一手事实可以升级。

把“没有被材料证明”与“现实中没有形成”分开。若证据包只是没有提供客户通知、订单、收入或回款，只能写“未被证据闭合”“包内未观察到”或 `NOT_EVALUABLE`，不得写“未收到”“未形成”“不存在”或含义相同的“无可归属暴露”。“后续以正式通知为准”也不证明通知尚未收到；只有具名一手事实明确否认、终止或确认未发生，才可形成对应的否定主张。

这条约束同时适用于标题、根结论、摘要、表格和主张卡，不能在后文纠正而让承重结论保留越界表述。缺证据时根结论采用同一语义：`证据包未闭合可归属暴露；现实中是否已形成未知，因此 NOT_EVALUABLE`。交付前检查全部否定式结论，逐条确认其具名否定事实，而不是材料沉默。

## 非对称审计

按问题选用以下模块：

- 主题层：瓶颈排序、利润池位置、替代技术和迁移条件；
- 公司层：业务口径、客户、合同、收入、毛利、现金与融资约束；
- 市场层：共识、价格/估值、拥挤代理、尚未定价的分叉；
- 时间层：事件日、战术周、业绩季度、结构年份分别判断；
- 行动层：触发器、失效条件和唯一最低成本下一验证。

常见错误：需求增长不等于便宜；政策目标不等于公司受益；预案不等于生效规则；签约产能不等于交付；单一机构事件不等于行业结论；热门名单不等于价值捕获；供需同时变化时不能压成一条因果。

## 完整报告格式

只有用户要求完整投资报告时，按需组合：

1. 根结论、适用时间和唯一下一步；
2. 可能性地图；
3. 承重主张卡与最弱环节；
4. 主题利润链和公司经济暴露；
5. 已定价 / 未定价对照；
6. 不超过 3 个具名载体或明确说明没有可用载体；
7. 反例、证伪条件和未决问题；
8. 决定性主张 `[C#]` × 来源 `[E#]` × URL × 发布日期。

长度服从信息量。投资语义只属于本 profile，不得成为非投资任务的默认输出合同。

## 可选市场数据脚本

需要 A 股价格硬锚时，可运行 Skill 安装根目录下的 `scripts/free_market_observations.py`。输入、输出与凭据边界以脚本帮助为准；输出只提供观察，不自动形成推荐。Tushare token 不进入提示、报告、锚或仓库。通用原始数据可按需使用 `scripts/tier1_providers.py`。
