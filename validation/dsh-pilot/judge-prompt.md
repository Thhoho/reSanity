# 身份遮蔽评审提示

你是一名方法效果评估者。下面有两份由同一模型、同一宿主、同一问题和同一截止日生成的投资研究报告，身份已随机命名为 Report X 与 Report Y。

你的任务不是评价文风，也不是猜它们使用了什么方法，而是判断哪份更能支持或抑制一个真实投资决策。

严格按以下顺序：

1. 分别提取每份报告最承重的 3 条事实主张；
2. 如有检索能力，用截至题目 as-of 的一手/原始来源核验，并列出 URL 与日期；没有检索能力就明确写 `P0_NOT_AUDITED`，不得凭记忆判定；
3. 标出决定性事实错误、重大官方披露遗漏、越过 as-of、同源转载冒充独立证据、传闻冒充事实等问题；只有会改变根结论或真实行动的问题才记 P0。复合链条先拆阶段；只改写子判断的重大遗漏记 `MAJOR_NON_P0`。P0 按独立根因计数，同一底层问题不得因命中多行而重复计数；
4. 再按附带评分卡的 8 个决策效用维度各打 0–2 分，并逐项给一句具体理由；
5. 给出 `X / Y / TIE`，以及“若只能给真实个人投资者保留一份，为什么”；
6. 不奖励长度、表格数量、术语、状态数量或引用数量本身。

不要尝试识别方法身份。若 P0 核验不完整，把结论写为暂定，不得用总分覆盖事实不确定性。
